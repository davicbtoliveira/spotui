# SpotUI

SpotUI is a terminal client for browsing Spotify music and controlling Spotify playback.

## Language

**Library**:
The user's saved Spotify content and personal browsing surfaces shown in SpotUI, including playlists, saved tracks, and top artists.
_Avoid_: Catalog, collection

**Track Search**:
A Spotify catalog lookup for playable track results matching a user-entered query.
_Avoid_: Music search, song search

**Search Result**:
A track returned by Spotify search that can be selected and played from SpotUI.
_Avoid_: Hit, match

**Tracks Tab**:
The library tab that shows the user's saved tracks.
_Avoid_: Musics tab, songs tab
