# License SpotUI under GPL-3.0

## Status

Accepted

## Context

SpotUI will integrate go-librespot in-process. go-librespot is distributed
under GPL-3.0, so the combined distributed work must use a compatible license
and comply with its source-distribution requirements.

SpotUI does not currently include a repository license.

## Decision

SpotUI will be licensed under GPL-3.0.

The implementation phase will add the full license text, copyright notice, and
source/release notices required for distribution.

## Consequences

- Modified SpotUI distributions must provide corresponding source under
  GPL-3.0.
- Dependencies and release artifacts must remain GPL-compatible.
- Contributors and users receive GPL-3.0 rights and obligations.
- Release automation must ship required license notices.
